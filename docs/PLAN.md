# 开发计划（Project Plan）

> 本文件记录 **Minecraft Fluent Launcher（MFL）** 的开发计划，遵循 [AGENTS.md](../AGENTS.md) 的流程要求。
> 最后更新：2026-09-12

---

## 1. 项目目标

开发一款 **Minecraft 启动器** 桌面应用，产品名 **Minecraft Fluent Launcher（MFL）**，基于 WinUI 3（Windows App SDK）。

**当前阶段：UI 优先。** 本阶段只交付界面与交互骨架，使用 **Mock 数据**，不接入真实的游戏下载、账户认证与 JVM 启动逻辑。

## 3. 更新规模

依据 AGENTS.md §11 / §12，按超大更新处理：整体确认 → 拆解为大更新 → 再拆解为小更新。

## 7. 工作流

每个小更新：**实现 → 构建/测试 → Commit → Push**。

## 8. 已知限制与待验证

| 项 | 说明 | 处理 |
|---|---|---|
| 运行时渲染未验证 | 全部 XAML 目前只验证到「编译通过 + 生成 `.xbf`」，未在本机运行确认 | 需用户运行确认 |
| 主题切换与 Mica | WinUI 3 的 `Application.RequestedTheme` 启动后不可变；当前通过设置根元素 `RequestedTheme` 切换，Mica 背景与系统窗口按钮**可能不跟随**变化 | 运行时确认后再定方案（重建窗口 / 重启提示） |
| 主题选择器重复 | 主题下拉同时存在于侧边栏底部（`MainWindowViewModel`）与设置页（`SettingsPageViewModel`）；两处独立持有状态，切换后另一处不会立即同步 | 大更新 ⑤ 统一为单一主题状态源 |
| 页面视图模型为单例 | 页面由 `Frame.Navigate(Type)` 反射创建，无法构造函数注入，故通过 `App.GetService<T>()` 取视图模型，且注册为单例（导航往返不丢状态） | 若后续需要多窗口 / 多实例，改为页面工厂 + 瞬态注册 |
| 语言切换 | 设置页可切换语言并已持久化，但界面文案尚未本地化 | 大更新 ⑤ 或后续版本引入资源本地化 |
| 日志级别颜色 | 日志列表以「错误 / 警告 / 其它」三色指示点表达级别，未做逐级配色 | 大更新 ⑤ 视需要细化 |
| 应用数据目录名 | ~~硬编码为 `MinecraftLauncher`~~ ✅ 已改为 `MinecraftFluentLauncher`（旧目录中的设置不会被读取） | 已完成 |
| Git 远端 | 尚未配置仓库地址，只能本地 Commit，**无法 Push** | 待用户提供地址 |
